# Truck Game

A simple truck driving game where the player controls a truck and navigates through a road with obstacles. The game is built to practice core game development concepts like player movement, collision detection, and input handling.

---

## 📌 About the Project

This project is a basic truck game that allows a player to:
- Control a truck using keyboard inputs
- Avoid obstacles on the road
- Stay on the road for as long as possible
- Track score or distance (if implemented)

The project helps to learn and understand game development fundamentals such as movement mechanics, physics, collisions, and basic UI.

---

## 🛠️ How to Play

1. Open the project in the appropriate game engine (like Unity or Phaser, depending on how this repo is implemented).
2. Use keyboard controls such as:
   - **Arrow keys / WASD** to move the truck
   - **Space** (optional) for actions like honking or braking
3. Avoid obstacles and try to get the highest score/distance.

> This README assumes common controls; adjust based on your implementation.

---

## 🚀 Features

- Truck movement using keyboard input  
- Obstacle spawning  
- Score or distance tracking (if present)  
- Simple road environment  
- Basic collision detection  
- Simple UI showing score or game status
